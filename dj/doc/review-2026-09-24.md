# DJ review — 2026-09-24

Full review of the Mac skill, the phone app and the engine's skill-sync lane.
Tests at review time: Mac 64/64, phone 93/93, `flutter analyze` clean — the
bugs below sit where no test reached. Status column is updated as fixes land.

## Phase 1 — bugs

| # | Where | Bug | Status |
|---|---|---|---|
| M1 | `actions.mjs` readJson | Any parse error returns `{}`; the next verb persists it — a truncated `library.json` wipes every song and playlist (reproduced). | fixed — parse error keeps `library.json.corrupt-<mtime>` and stops the verb; only ENOENT falls back (`io.mjs`) |
| M2 | `actions.mjs` lock | Deadline is the waiter's, not the lock's age — a waiter steals a live holder's lock; `unlock` removes whoever holds it. | fixed — holder writes its pid; takeover only when the pid is dead or the lock is >30 s old; unlock removes only its own |
| M3 | `bash.js` writeFile | Paths in double quotes: `$` / backtick in a name write the wrong `.lrc` (endless backfill) or run a command. | fixed — `writeFile` resolves and `sq()`s the path; every name-derived shell string audited (`bash.js`) |
| M4 | `download.js` / `get.sh` / `karaoke.sh` | `safe()` and ID3 tags differ between page and agent paths — one song, two names. | fixed — one `naming.py` + `fetch.py` for page, GetTracks, GetKaraoke and the queue; `test_naming.py` pins names |
| M5 | `karaoke.sh` / reconcile | `GetKaraoke` never lights 🎤 — reconcile only clears karaoke fields. `AGENT_WRITERS` misses AddToPhone / RemoveFromPhone / GetKaraoke. | fixed — reconcile finds `.karaoke/<stem> (Karaoke).{mp3,mp4}`; GetKaraoke reconciles; `AGENT_WRITERS` complete |

| M8 | `actions.mjs` tracks-delete | Unlinks files before persisting. | fixed — persist, then unlink |
| M9 | `dj.js` toast | `esc()` into a `textContent` toast shows `&amp;`. | fixed — toasts take plain text; `confirmDialog` escapes its own message |
| M10 | picker / `lyrics_match.py` | A song asked for by a wrong title (風中密碼 for 風裡密碼) lands under it, finds no lyrics and is stamped for a month. | fixed — the album track's own title (same-title/artist rule or a lyrics length within 5 s), in the asked script, names file, tags and row; `requested_title` kept; lyrics retried under the other title |
