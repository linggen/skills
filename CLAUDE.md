# Claude Code Instructions

This is the Linggen skills repository. It contains reusable AI skills for Claude Code, Codex, and Linggen Agent.

## Skills

- **`memory/`** — Semantic memory, RAG, code search, prompt enhancement, codebase indexing. Requires `ling-mem` server.
- **`skiller/`** — Skill marketplace: search, install, browse library packs.
- **`discord/`** — Discord social messaging.
- **`linggen/`** — Deprecated. Points to `memory` and `skiller`.
