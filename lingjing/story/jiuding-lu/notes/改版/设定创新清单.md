# 设定创新清单 · 卷一（2026-10-02，作者：「创意第一，设计设定等要有创新」）

尺子：同类小说里见过没有？见过的，拧在本书自己的东西上（九鼎、九州、《禹贡》、山海经、猎户、记账、饿），或换掉。★ = 推荐。作者挑定之前，正文不动。

## 一 · 老套，要拧

### 1. 饭桶（外挂丹炉）
- 同类：《凡人修仙传》掌天瓶——随身神器，灵草催熟、丹药翻倍，主角的发家之本。饭桶「出主人境界的九转丹」几乎是同一个挂。
- A ★ **只炼给别人**：饭桶炼给自己吃的丹，一出炉就化灰；炼给别人的，九转。挂变成了一道选择题——他要变强，只能靠别人还的丹、换的丹、自己拼的修为；他的丹永远在送人。接「回春丹给爹」「爹的丹喂给老胡」，人设「护人」落在挂上。代价：古七他自己吃的九转筑基丹要改来路（比如阿禾拿自己的丹换、或饭桶炼给银月、银月吐给他）。
- B **饭桶是一只鼎的心**：九鼎每回一口，饭桶长一条腿/一只耳，能炼的东西变一样。挂随主线长，不随境界长。
- C **饭桶要吃饭**：每炼一炉，吃掉他一顿饭的饱——他本来就「特长：饿」。炼得越多，他越饿，饿到眼前发黑也得炼。

### 2. 灵根与测灵石
- 同类：水晶球亮颜色，单灵根天才、杂灵根废柴，后来废柴逆袭。
- A ★ **灵根是土**：《禹贡》九州各有土色，徐州「厥贡惟土五色」——天下只有徐州贡五色土，铸鼎、筑社稷坛用的就是它。五行杂灵根不是「杂」，是**五色土**：社稷的土、九鼎的土。测灵石照他亮出五色，满殿当他是废物；只有瞿老、观主心里一沉。九鼎缘人的身份落在他的出身上，不靠「天命之子」。
- B **测灵石量的是缺**：石头亮的是你**缺**的颜色。单灵根缺四样，亮四色；他五样都有，石头一样也不亮——满殿判他「无灵根」，其实是五行俱全。笑点和真相在同一块石头上。

### 3. 境界的叫法（练气一至九层）
- 同类：练气 N 层，人人一样。
- A ★ **他自己的器皿梯子**：官面上照叫练气几层；他心里只认自己的——漏勺（已有）→ 碗 → 水缸（已有）→ 井 → 塘……每升一层，他换一样家里的东西来比。读者记住的是「他从漏勺长成了一口井」，不是「五层」。不改世界设定，只改他看世界的眼睛。
- B 境界以九州的水量：练气是「泗水一勺」，筑基是「一条泗水」……接鲁泥鳅「讲理的河」。

### 4. 外门大比、头名赏筑基丹
- 同类：宗门大比，擂台，夺魁得丹。
- A ★ **大比是一门生意**：沉鼎观穷（已卖名牌）——大比卖门票给山下、钱掌柜开盘口、世家押注；台上打得越狠，赔率越高，观里抽水。弟子是赛马。残酷落在制度上：你在台上拼命，台下有人拿你赚钱。小满看懂了，自己押自己。
- B 大比赛的不是打，是**三天活着从秘境里带出最多的东西**——秘境与大比合一（但古五、古六已分开写，改动大）。

### 5. 法宝认主、杀人夺宝
- 同类：杀了人，宝贝归你，滴血认主。
- A ★ **死人的法宝守七天**：主人死了，法宝还认他七天，七天里谁碰谁遭反噬——秘境里抢宝死的人，一半死在死人的宝贝上。所以小满捡的是凡铁（聪明，不是穷）；反派那面盾，银月破了，七天后才是废铜。残酷又讲理，也解释了为什么人人抢灵草、少有人抢法宝。
- B 法宝记账：每杀一人，法宝重一分。号称无敌的盾，重得要两只手才举得动——那是一百多条命。

### 6. 储物袋
- 同类：储物戒指、乾坤袋。
- A ★ **银月的肚子就是储物袋**（已有「吐出丹炉」）：她吞下去的东西，存久了会被她**消化**——放得越久，灵性越少；她一饿，会偷吃他的东西。存东西要跟她讨价还价（一张饼存三天）。接「欠一张饼」。
- B 小满没有储物袋，只有一个红糖纸订的本子：东西记在本子上，就算「存着」——一个猎户的账，偏偏后来真灵了（太玄，慎用）。

### 7. 符箓
- 同类：画符念咒，符分品阶。
- A ★ **符是画的人的心思**：画的时候心里想什么，符就成什么。银月想画云、心急，画成了马——「踏马的符」（已定）。往后：小满不识几个字，他画的符全是他账本上的记号（圈、杠、勾），歪打正着，各有怪用。一门只有他画得出的符。
- B 符要「付钱」：每画一道，画的人掉一样东西（一根头发、一夜的梦）。

### 8. 秘境（已拧大半）
- 已有：河底十年翻身吸一口气、门认名牌、卖名牌、蛫是门闩、四百人死一大半。
- 加一层 ★ **秘境要吃够人才合门**：鲁泥鳅的「翻身吸气」是真的——河底那东西吸进去的不只是水。玄沉子数名牌，数的是「它吃够了没有」。卷一只露一句（周衡账上那几页红杠，十年一页，一页比一页长），解在后卷九鼎/相柳。接「修仙是残酷的」：秘境本身就是一张嘴。

### 9. 灵石
- 同类：通用货币兼修炼资源。
- A **灵石是泗水的沙**：秘境吐气时冲上岸的沉沙，十年一回，观里垄断——所以沉鼎观靠秘境活着、靠卖名牌活着。小满是水缸，一口一块，穷得最快。
- B 灵石会「旧」：放一年，灵气散一半——穷人存不住，富人用不完。

## 三 · 推荐先定的三件（牵动最大、最出彩）
1. **灵根 = 五色土**（2A）：一句《禹贡》把主角、徐州、九鼎拴在一起。改动小：古三测灵那一段、瞿老与观主的反应。
2. **饭桶只炼给别人**（1A）：挂变成人设。改动中：古七筑基丹的来路。
3. **死人的法宝守七天**（5A）：秘境残酷的规矩，正好用在现在改的古五。改动小。
