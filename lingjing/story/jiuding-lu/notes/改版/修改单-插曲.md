# 修改单 · 今线插曲 01–04 — 审稿 + 冷读者第一轮合并（2026-10-02）

## 必改（科学 / 逻辑）
1. 插曲01「是借着氧气跑的」→「是欠着氧气跑的，欠了要还，所以停下来还喘半天——这叫氧债」。
2. 插曲01「倒有一大半是在给气管喘的」→「白喘了好几成」；「进不到肺」→「到不了肺泡」。
3. 插曲02 阿禾「一松……人就黑了」与场面不符 → 「憋得越久，回心的血越少，脑子先缺了血，人就黑了；一松那一下，血压还要再掉一截。」
4. 插曲03 尿黑因果 → 「肉里的肌红蛋白漏进血里，从肾里滤出来，尿便成了酱色；滤得太多会堵、会伤肾」；「就没事」→「多半没事」。
5. 插曲03 肌酸激酶带单位：「四万二，单位是 U/L……正常人一两百」。
6. 插曲03 出院三条 → 「晨脉回到七十以下，才许摸球；摸了球，只许罚球；十二月六号复查抽血。」
7. 插曲04「筋、骨头、肉……也不大丢得掉」→「骨头、肉、毛细血管，开始量得出来」，删「也不大丢得掉」。
8. 插曲04 三焦经接胆经的笑话本身是对的 → 换真错的，如「把手太阴肺经一路画到了脚上」。
9. 插曲01 眼镜「我查了」三次 → 留一次。

## 冷读者放下点（2.2a；3.7a）
10. 插曲02「看书的诸位不妨这会儿按着腕子」叫读者放书 → 改成沈芒自己按腕子（读者想试自会试），旁白不点读者。「吸四吐六」加「一拍一秒」。
11. 插曲03「所言节者……合穴、五行属土」——他正等脚能不能上场 → 典留（{典}），挪到结果出来之后，压短；严老师讲足三里那段压一半。
12. 插曲01「一百五十毫升停在气管」刚吐完就上数字 → 挪开一拍或去掉数字留比方。十二经接力、岛叶内感受压短。
13. 新人：大刘在插曲03 突然出场 → 前面一段里先让他露一面（一句：谁、多高、为什么在队里）；「忙哥 / 沈忙」第一次出现处交代是外号；雷老师（体育、教练）/ 严老师（针灸课）第一次并出时一句分清。
14. 并稿的缝：插曲02「那是他三个礼拜前教老蔡的」→「那是三个礼拜前老蔡笑他『漏气』的那一口」；插曲03「九月里阿禾说过」→「他在哪儿看过一句」；插曲03「九月里他说吃的是食堂」→「十月里两回」。

## 应改
15. 插曲02 刚晕过去半个钟头又推三十公斤 → 阿禾「头不晕、不恶心，才许碰杠」+「一个人别推，架子上有保护杠」。咖啡因「借完了要还」→「它让你不觉得累，不长肉」。插曲03「这一篇末了」→「这一段末了」。马小宝喘「又急又浅/又急又深」统一「又急又多」；「吹空了」→「吹低了」。「三口锅」旁白压到三句。插曲01 L31、插曲04 L183 引文繁体 → 简体。
