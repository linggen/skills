# 灵境 · 重设计 v2（已拍板 2026-09-24）

> 2026-09-24。起因：设计师视角复盘的结论是「底子扎实，但像个工具箱，还不像一段旅程」。
> 这一版的目的只有一个：**做减法，让每一分钟都好玩，让人想明天回来**。
> 2026-09-24 全部同意（含砍历练、伤势，每日三件）。按「落地顺序」分批改。

---

## 一、核心幻想（一句话）

**两个懂你的 AI 伙伴，陪你走完一段只属于你的修仙路。**

- **Ling** 是说书人，掌管世界和故事。
- **银月** 是身边的伙伴，看着你、记得你。她自己也有一段要走完的路：九鼎每寻回一个，就拿走她的一个倒影。
- 一个系统进不进游戏，就看它服不服务这句话。

## 二、三根支柱

| 支柱 | 意思 | 玩家感受到的 |
|---|---|---|
| **斗法** | 卡牌斗法是唯一的「技能核心」，玩家的成长主要体现在牌组上 | 「我这副牌越来越强，打法越来越多」 |
| **牵挂** | 主线九鼎和银月的身世是同一条线，每一步都有代价 | 「我想知道接下来会怎样，我舍不得银月」 |
| **因你而变** | Ling 写的传闻、你做的选择、遇到的熟人都会留下来，而且会回来 | 「这个世界记得我做过什么」 |

所谓生活联动（人间功课、开府），是支撑这三根支柱的「燃料」，本身不是支柱。

## 三、循环

**一分钟：打一场斗法或解一局棋，赢了立刻看到收获。**
页面自己结算，Ling 只讲故事，所以操作永远不用等模型。

**一次坐下（20–40 分钟）：**
1. 打开游戏：银月问候，Ling 念前情提要（隔天回来时）。
2. **今日传闻**：3–5 步，每步一局小游戏，最后打首领。这是「今天的主菜」。
3. 顺路：主线往前推一幕，或者打一只路上的灵兽。
4. 体力用完：银月让你起身歇歇，今天就到这里。

**一天：** 一个今日传闻，一件人间功课，外加想推多少主线都行。
**一周：** 主线一章（六幕加一个鼎），外加牌组里多了几张好牌。
**一辈子：** 九鼎归位，银月是完整的，她选择留下。

## 四、系统：留、合、砍

### 留（核心，继续做深）

| 系统 | 为什么留 | 要改什么 |
|---|---|---|
| **卡牌斗法** | 唯一有深度、有模拟器把关的系统 | 成为冲突的默认解法：精英怪、传闻首领、剧情战斗都用它；新卡从剧情和传闻里拿 |
| **主线九鼎** | 故事的骨架 | 九鼎录、章节标题卡、前情提要（已在做） |
| **今日传闻** | Ling 发挥最大的地方 | 已上线；下一步把选择的后果和熟人回访做出来 |
| **银月身世线** | 全游戏最有情感重量的设定 | 已在写进游戏；「倒影的代价」要从第 4 章起让玩家隐约感到 |
| **境界 · 修为** | 大目标，也是主线的关卡 | 不变 |
| **体力** | 唯一的节奏阀门 | 不变 |
| **小游戏（6 种棋局 + 论道）** | 调剂，也是传闻的步骤 | 不再单独当每日功课刷，只在传闻和剧情里出现 |

### 合（几个系统并成一个）

| 现在 | 合成 | 理由 |
|---|---|---|
| 遇 · 拾遗 · 抉择 · 机缘 · 拦路灵兽 | **「路上」**：到一个地方时最多发生一件事 | 五个名字玩家记不住，其实都是「路上碰到的事」 |
| 差事 · 榜文 · 功课（棋局） | **「差事」**：只有一种，由人给你 | 功课棋局并进今日传闻，榜文就是差事 |
| 起卦 · 望气 · 命格 | **「问卦」**：一天一次，影响当天的斗法手气 | 三个都是「看运势」，一个就够 |
| 羁绊 · 谈心 · 疗伤 | **银月**：她跟你的关系只看你们一起经历了什么 | 不给关系打分，让它自然流露在她的话里 |
| 装备 · 本命法宝 · 符 | **法宝**：一件随你成长的本命法宝，加上消耗品「符」 | 普通法衣、佩戴冻结，只保留一件会成长的东西 |

### 砍（或冻结，不再加深）

| 系统 | 处理 |
|---|---|
| 伤势 | 冻结。输了只是今天不能再打这只妖，不另外扣数值 |
| 精英的独立机制 | 并进斗法：精英就是更难的牌组，不单独设规则 |
| 温养 · 强化的每日点击 | 砍掉，本命法宝改成随剧情和传闻成长 |
| 写符的每日点击 | 砍掉，符改从斗法和传闻中掉落 |
| 历练（派银月出门几小时） | 冻结。它跟「银月陪在你身边」这个幻想相冲突 |
| 组牌手动十张 | 保留自动，手动组牌放到结丹以后再开放 |

**结果：** 每天要重置的事，从十四项左右降到**三项**：今日传闻、一件人间功课、一次问卦。

## 五、斗法成为核心

- **牌从故事里来。** 每只收服的灵兽、每个传闻的首领、主线每一章都给一张有名字的牌。牌组就是你这一路的回忆。
- **五行即流派。** 你的灵根决定主流派，法宝借来的属性开第二流派。到后期，两副不同的牌打起来手感完全不同。
- **首领有台词。** 斗法开始和结束时，Ling 为首领写一句话，银月在你身边说一句。
- **看得见的成长。** 九鼎录里有一页「牌谱」：你拿到的每张牌、从哪里得来的。

## 六、故事：牵挂和因你而变

1. **九鼎录**（已在做）：随时看主线、人物、银月记起了什么、还没解开的谜。
2. **前情提要**（已在做）：隔天回来，先听两三句「上回说到」。
3. **银月的代价要早点露出来。** 从第 4 章起，每寻回一个鼎，她都会有一点小异样：话少了一句，或者在水边多站了一会儿。玩家会察觉，但说不清是什么。到第 8 章她才说出来。这是全游戏最大的钩子。
4. **熟人回访。** 今日传闻里认识的人会再出现，而且记得你当时怎么对待他。
5. **选择有后果。** 传闻的结局可以有两种，比如放走妖，或者降了它。下次路上会遇到后果：报恩，或者寻仇。规则只记一个标记，由 Ling 来写。

## 七、生活联动（Linggen 的差异点）

- **人间功课：** 固定一件运动，外加每天抽一件（电脑、手机轮流）。已在做。
- **开府：** 一次性成就，引导玩家把 Linggen 用起来：配手机、接模型、装插件……已在做。
- **定位：** 生活联动是给修行加的燃料，不是必做的功课。不做也不罚，做了让你修得更快，同时让你把 Linggen 用起来。

## 八、画面

- **舞台：** 一次只放一件事（已上线）。
- **顶栏：** 境界和修为、体力、「录」（九鼎录）、「事」（手上的事）、「宝」（法宝和牌谱）。
- **聊天：** Ling 讲故事，银月说话；@银月 问她（引擎部分已完成，等部署）。
- **斗法：** 占满整个舞台（不变）。

## 九、前十分钟（要专门打磨）

| 时间 | 发生什么 | 玩家应该感到 |
|---|---|---|
| 0–2 分钟 | 泗水边的银光、名字、测灵根 | 「这个世界有来历」 |
| 2–5 分钟 | 第一场斗法（教学），赢了拿到第一张牌 | 「这个打起来有意思」 |
| 5–8 分钟 | 第一个小传闻（简化版，两步） | 「故事会跟着我走」 |
| 8–10 分钟 | 引出九鼎和「月下之约」的钩子 | 「我想知道后面」 |

打磨方法：找两三个没玩过的人，看着他们玩前十分钟，记下哪里卡住、哪里笑了。

## 十、落地顺序

1. **已在做，不变：** 银月身世和存在感；九鼎录和前情提要；第 4–9 章；人间功课和开府；部署 @银月。
2. **合并「路上」：** 遇、拾遗、抉择、机缘、拦路合成一类（规则加页面）。
3. **合并「差事」：** 功课棋局并进传闻，榜文即差事。
4. **冻结和砍：** 伤势、温养强化、写符、历练、手动组牌，连同相关的每日点击。
   - 存档迁移：已有的物品和状态保留，只是不再产生新的。
5. **斗法成为核心：** 牌从故事里来、首领台词、牌谱页。
6. **银月代价的早期暗示：** 第 4–8 章的小异样。
7. **打磨前十分钟和新手流程。**

每一步都保持测试全过，玩法有数值变化时跑斗法模拟。

## 十一、要你拍板的

1. 核心幻想这一句，对吗？
2. 「合」和「砍」两张表里，有没有你舍不得的？尤其是**历练**和**伤势**，这两个是你前几天刚要的。
3. 每天只剩三件事（传闻、人间功课、问卦），够不够？会不会太少？
4. 斗法当核心，小游戏只当调剂和传闻的步骤，你同意吗？
