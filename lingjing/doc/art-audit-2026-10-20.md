# Small-game art audit (2026-10-20)

Rules it is measured against: every picture is painted by the image model, code only animates (10-16);
comic / Angry-Birds style (10-19); benchmark 《向僵尸开炮》 (10-20).

Key — **P-comic**: painted, comic. **P-ink**: painted, but the old 水墨 house style (paint-games.py,
paint-rope-flux.py, paint-laobing-flux.py, paint-wuziqi-flux.py): painted, yet off the 10-19 comic ruling.
**Code**: SVG / canvas / CSS shapes or a Python-drawn atlas. **Glyph**: a character standing in for a thing.
**Chrome**: buttons, panels, HUD text, which the shared shell will take over later (listed, not repainted).
Sizes: u = scene units; rope boards 360×440 u ≈ 1 px/u, throw boards 480×300 u ≈ 0.83 px/u (card ≤ 400 px).

Skipped: the games the weak-board merge deletes (tag `wip/2026-10-19-weakboards`, cb7a1c3f): deerhunt,
storm, deer row, griddle, carry, feather, xisui, zhoutian, mirrortongpu, leafsui, leafding, huohousmell,
zhuqingting, letter, reed, qianmi, faqiu, dark, lastshot, caveecho, qiajue, xiangke, diche, pulse, recipe,
kaipian, wind, descend, gather, shouye, scale, taunt, way.
