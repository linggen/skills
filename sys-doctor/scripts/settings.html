Sys Doctor Settings

Bring your own model and search keys. Sys Doctor uses the model you pick to analyze your system, and Tavily for any web lookups.

Model

Pick which AI provider Sys Doctor uses, and paste your API key. Local models (Ollama) work without a key. Cloud providers need their respective keys.

Web Search

Add a Tavily API key to enable web search during analysis. Free tier at tavily.com is enough for personal use. Optional — Sys Doctor still works without it.
