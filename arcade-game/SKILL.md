# Arcade Game Collection

A collection of classic retro arcade games playable directly in the browser.

## Games

- **Snake** — Chase food and grow longer
- **Pong** — Local two-player paddle battle
- **Tetris** — Stack pieces, clear lines, chase high scores

## Controls

- **Snake**: Arrow keys to move
- **Pong**: W/S for Player 1, Up/Down for Player 2
- **Tetris**: Left/Right move, Up rotate, Down soft drop, Space hard drop, P pause
